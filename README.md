# Banco de Dados - Universidade

<p align="center">
  Projeto acadêmico de Banco de Dados com SQL Server 
</p>

## - Sobre o projeto

Projeto desenvolvido para a disciplina de Banco de Dados, com o objetivo de implementar um sistema de gerenciamento acadêmico utilizando SQL Server.
A atividade envolve a criação e manipulação de dados de alunos, matrículas, notas e faltas, por meio de scripts SQL e procedures responsáveis por automatizar processos e aplicar as regras de aprovação, reprovação e exame.
